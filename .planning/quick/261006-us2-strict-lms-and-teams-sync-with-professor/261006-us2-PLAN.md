# Quick Plan: Strict LMS and Teams Sync with Professor & Student Matching

## Context
User request:
"when synced lms and teams should fetch the latest assignmetns pending and if done marked done but everyassitgnment belong to the student and faculty should be fetched only if the student and professor matched"

## Tasks

### Task 1: Enforce Strict Faculty & Course Matching in LMS Scraper & Router
- **Files**: `backend/app/routers/lms.py`
- **Action**:
  1. In `_process_single_lms_course`:
     - Verify that `match_meta.courseCodeMatch` AND `prof_matched` (or `match_meta.facultyMatch`) are BOTH true.
     - If professor does not match the student's enrolled VTOP course faculty, fail verification (`match_meta.verified = False`, `match_meta.facultyMatch = False`), log the rejection reason, and return without fetching any assignments for that course.
  2. In `fetch_assignments_for_lms_course`:
     - For each candidate assignment in the course: if an explicit poster/instructor is detected and does NOT match the enrolled VTOP professor, skip/exclude that assignment.
     - Ensure authentic submission evaluation:
       - If submitted/graded/turned in/completed: set `isDone: True`, `isSubmitted: True`, `status: "Submitted"`, `applicationStatus: "DONE"`.
       - If pending/not submitted: set `isDone: False`, `isSubmitted: False`, `status: "Pending"`, `applicationStatus: "PENDING"`.

### Task 2: Enforce Strict Faculty & Course Matching in Teams Scraper & Router
- **Files**: `backend/app/routers/teams.py`
- **Action**:
  1. In `_process_single_team`:
     - Require `if is_verified and matched_rec:` (remove `or match_meta.courseCodeMatch`). If professor in Teams does not match the student's enrolled VTOP course faculty (`is_verified` is False), do not fetch assignments.
  2. In `fetch_assignments_for_matched_team`:
     - Ensure assignment status: if turned in / submitted / graded / completed -> `isDone: True`, `status: "DONE"`, `applicationStatus: "DONE"`. If pending / not submitted -> `isDone: False`, `status: sub_meta["applicationStatus"]`, `applicationStatus: sub_meta["applicationStatus"]`.
     - Exclude any assignment if explicit author/faculty is detected that conflicts with the enrolled professor.

### Task 3: Enforce Assignment-Level Faculty Matching in Unified Assignments & Add Regression Tests
- **Files**: `backend/app/routers/unified_assignments.py`, `backend/tests/test_lms.py`, `backend/tests/test_teams.py`, `backend/tests/test_unified_assignments.py`
- **Action**:
  1. In `backend/app/routers/unified_assignments.py`:
     - In `build_unified_assignment_dashboard`: When verifying assignments against student's enrolled courses, ensure that if an assignment has a specified faculty or poster that does NOT match the enrolled VTOP faculty, it is rejected and excluded (`fac_matches = False`). Remove blind trust of `verifiedCourseMatchId` for unmatched faculty.
     - Ensure proper calculation of `isDone`, `status`, `applicationStatus`, and counts (`totalPendingAssignments`, `totalSubmittedAssignments`).
  2. Add unit tests:
     - Test that LMS courses and assignments with conflicting professors are not synced.
     - Test that Teams channels and assignments with conflicting professors are not synced.
     - Test that matching professor coursework is synced and correctly marked `DONE` vs `PENDING`.
     - Run `pytest backend/tests` to ensure 100% test pass rate.
